## Kratki opis funkcionalnosti

GuitarQuest je web aplikacija namijenjena početnicima i rekreativnim gitaristima za učenje gitare i praćenje vlastitog napretka.

Aplikacija omogućuje:

- registraciju i prijavu korisnika
- pregled gitarskih akorda
- označavanje akorda kao _Learning_ ili _Learned_
- pregled gitarskih pjesama
- označavanje pjesama kao _Learning_ ili _Learned_
- unos vremena provedenog u vježbanju
- sustav XP bodova i razina (Level)
- dnevni niz vježbanja (Streak)
- sustav izazova (Challenges)
- pregled statistike napretka putem Dashboarda
- korisnički profil
